# Bloom Widgets – support

Home screen widgets for Android: countdowns, clock, alarm, weather, app links, a weekly planner,
photos and a pet feeding schedule.

## Get help or report a problem

[Open an issue](../../issues/new) and describe what happened, which widget, and your phone or tablet model.

## For MET Norway (api.met.no)

The Bloom Widgets app fetches weather forecasts from MET Norway's Locationforecast 2.0 API and
identifies itself with the User-Agent `BloomWidgets/<version> https://github.com/s-aurelyon/bloom-widgets-support`.
If its traffic causes any problem, please open an issue here and it will be dealt with promptly.
